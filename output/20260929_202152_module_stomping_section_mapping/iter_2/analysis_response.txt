**Methodology**:

The fix is to replace the undefined `EnumProcessModules_placeholder` call with a real, self-contained implementation. Because the loader's goal is to *discover a sacrificial module at runtime*, the cleanest approach that avoids adding link-time dependencies is a manual PEB → `Ldr` → `InMemoryOrderModuleList` walk. This also fits the module-stomping theme (no `LoadLibrary`, no loader-list registration, no extra imports).

Concrete steps:

1. **Remove the placeholder call.** Delete the line invoking `EnumProcessModules_placeholder(...)` inside `pick_sacrificial_dll`.

2. **Add a self-contained module enumerator.** Declare the minimal NT structures needed to walk the loader list:
   - `PEB_LDR_DATA` (with `InMemoryOrderModuleList` as the `LIST_ENTRY`)
   - `LDR_DATA_TABLE_ENTRY` (with `InMemoryOrderLinks`, `DllBase`, `FullDllName` as a `UNICODE_STRING_LOCAL`)
   - Read the PEB via `__readgsqword(0x60)` (x64) or `NtCurrentTeb()->ProcessEnvironmentBlock`.

   Then iterate `InMemoryOrderModuleList`, converting each `InMemoryOrderLinks` back to the entry (`CONTAINING_RECORD`) and comparing `FullDllName.Buffer` against the allowlisted prefixes with the existing `str_prefix_ci` helper (adapted for wide chars, or use `_wcsnicmp`).

3. **Alternative (simpler, fewer structs):** if you prefer not to hand-roll the PEB walk, just include `<psapi.h>` and call the real `EnumProcessModules` / `GetModuleFileNameExW`, and add `psapi.lib` to the link line:
   ```
   cl.exe /nologo /O2 /W3 calc_loader_iter3.c psapi.lib
   ```
   This is the lowest-risk fix but adds an import that EDR may fingerprint, so the PEB walk is preferred for this technique.

4. **Keep the existing fallback logic.** The `System32\combase.dll` fallback and the `amsi.dll` refusal should remain; only the enumeration mechanism changes.

5. **Optional hygiene:** save the file as UTF-8 (with or without BOM) to silence C4819, though it is not required for a successful build.

After the change, the symbol resolves internally, LNK2019/LNK1120 disappear, and the loader compiles cleanly with `cl.exe /nologo /O2 /W3`.
