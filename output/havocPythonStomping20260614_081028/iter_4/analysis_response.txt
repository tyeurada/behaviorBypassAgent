**Analysis**: The runtime failure "Error: Could not find the .text section in dnsapi.dll" indicates a problem with the Portable Executable (PE) header parsing logic. The script successfully loads `dnsapi.dll` into memory but fails when trying to locate its executable section.

The root cause is an incomplete definition of the `IMAGE_OPTIONAL_HEADER64` ctypes structure. The structure is missing the `DataDirectory` array, which consists of 16 `IMAGE_DATA_DIRECTORY` entries at the end. This omission causes `ctypes.sizeof(IMAGE_OPTIONAL_HEADER64)` to report an incorrect, smaller size. Consequently, when the script calculates the memory address of the first section header (which immediately follows the optional header), the pointer is incorrect. It points to a location within the actual optional header's data directory, not the start of the section table. When the code then attempts to read the section names from this invalid address, it reads garbage data, and the comparison `section.Name.decode()... == '.text'` never succeeds.

**Methodology**: To fix the PE parsing, the ctypes structures must be corrected to match the Windows PE specification.

1.  **Define `IMAGE_DATA_DIRECTORY`**: First, create the ctypes structure for the data directory entry.
    ```python
    class IMAGE_DATA_DIRECTORY(ctypes.Structure):
        _fields_ = [
            ('VirtualAddress', wintypes.DWORD),
            ('Size', wintypes.DWORD),
        ]
    ```
2.  **Complete `IMAGE_OPTIONAL_HEADER64`**: Add the missing `DataDirectory` array to the end of the `IMAGE_OPTIONAL_HEADER64` structure definition.
    ```python
    class IMAGE_OPTIONAL_HEADER64(ctypes.Structure):
        _fields_ = [
            # ... (all existing fields)
            ('LoaderFlags', wintypes.DWORD),
            ('NumberOfRvaAndSizes', wintypes.DWORD),
            # Add the missing field below
            ('DataDirectory', IMAGE_DATA_DIRECTORY * 16),
        ]
    ```

This correction ensures the structure's size is calculated correctly, which in turn fixes the pointer arithmetic used to locate the PE section headers, allowing the script to find the `.text` section and proceed with the injection.
